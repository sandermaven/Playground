# Book Landing Page: Als iemand dit bouwt, gaat iedereen dood

A modern, conversion-optimized landing page for the Dutch translation of "If Anyone Builds This, Everyone Dies" by Eliezer Yudkowsky & Nate Soares.

## Book Details

- **Title:** Als iemand dit bouwt, gaat iedereen dood
- **Subtitle:** Waarom bovenmenselijke AI ons einde kan betekenen
- **Authors:** Eliezer Yudkowsky & Nate Soares
- **Translator:** Jan Willem Reitsma
- **Publisher:** Maven Publishing
- **ISBN:** 9789493434400
- **Price:** €26,50 (paperback)
- **Release Date:** 24 March 2026

## Features

- Responsive design (mobile, tablet, desktop)
- Modern CSS with custom properties
- Accessibility-focused (reduced motion, focus states)
- Print-friendly styles
- SEO-optimized meta tags
- Google Fonts integration (Inter, Playfair Display)
- 3D book cover mockup
- Newsletter signup form
- Pre-order call-to-action buttons

## Usage

Simply open `index.html` in a web browser to view the landing page.

For development, you can use any local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (with http-server)
npx http-server

# Using PHP
php -S localhost:8000
```
